# DevaFlow Local Setup Guide (Laptop)

This guide explains how another person can run the full project locally:
- training
- inference
- Gradio UI
- all 5 analysis tasks
- ablation workflow (Task 4)
- Hugging Face deployment

## 1) System Requirements

- macOS/Linux (Windows via WSL recommended)
- Python 3.11
- 16GB+ RAM recommended
- Optional GPU (CUDA or Apple Silicon MPS)

## 2) Clone and Environment

```bash
git clone <your-github-repo-url>
cd Exclude_Negative
python3.11 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

If you use `uv`, run commands as:

```bash
uv run --active <command>
```

## 3) Check Project Structure

Required directories/files:

- `config.py`
- `train.py`
- `inference.py`
- `model/`
- `diffusion/`
- `data/`
- `analysis/`
- tokenizers:
  - `sanskrit_src_tokenizer.json`
  - `sanskrit_tgt_tokenizer.json`

## 4) Train Model

```bash
python train.py
```

Expected checkpoint location pattern:

- `results7/<model_type>_neg_<True|False>/best_model.pt`

## 5) Run Inference (CLI)

```bash
python inference.py
```

Or use API style:

```python
from inference_api import predict
print(predict("dharmo rakṣati rakṣitaḥ"))
```

## 6) Run Gradio UI (Local)

```bash
python app.py
```

Open the shown localhost URL.

UI supports:
- checkpoint selection (including ablation folders if present)
- inference parameter controls
- task runner for Tasks 1–5

## 7) Run Analysis Tasks

### Task 1
```bash
python analysis/run_analysis.py --task 1
```

### Task 2
```bash
python analysis/run_analysis.py --task 2 --input "dharmo rakṣati rakṣitaḥ"
```

### Task 3
```bash
python analysis/run_analysis.py --task 3
```

### Task 4
Task 4 needs retrained models for each diffusion step.

Generate configs:
```bash
python analysis/run_analysis.py --task 4 --phase generate_configs
```

Train all generated configs (script generated by Task 4), then analyze:
```bash
python analysis/run_analysis.py --task 4 --phase analyze
```

### Task 5
```bash
python analysis/run_analysis.py --task 5
```

### All Tasks
```bash
python analysis/run_analysis.py --task all --input "satyameva jayate"
```

Outputs are saved under:
- `analysis/outputs/` (or custom `--output_dir`)

## 8) Use Ablation Models in UI

Put ablation checkpoints at:
- `ablation_results/T4/best_model.pt`
- `ablation_results/T8/best_model.pt`
- `ablation_results/T16/best_model.pt`
- etc.

Then click **Refresh Models** in UI. They appear in dropdown automatically.

## 9) Hugging Face Model + Space Deployment

From `deploy_ready/`:

```bash
cd deploy_ready
export HF_TOKEN="hf_xxx"
../.venv/bin/hf auth login --token "$HF_TOKEN"
./deploy_hf.sh <hf_username> <model_repo_name> <space_repo_name>
```

For your current setup example:
```bash
./deploy_hf.sh bhsinghgrid DevaFlow DevaFlow-space
```

Space variables (Settings → Variables and secrets):

- `HF_CHECKPOINT_REPO=bhsinghgrid/DevaFlow`
- Optional: `HF_CHECKPOINT_REVISION=main`

## 10) Common Errors and Fixes

- `VIRTUAL_ENV ... does not match ... use --active`
  - Use `uv run --active ...` or activate the local `.venv`.

- `Cannot find empty port in range: 7860-7860`
  - Start Gradio on another port:
  - `GRADIO_SERVER_PORT=7861 python app.py`

- HF Space build import errors
  - Ensure `README.md` metadata includes `python_version: 3.11`
  - Keep pinned versions in Space `requirements.txt`

- Task 4 says no ablation models found
  - Train ablation checkpoints first; Task 4 analyze phase does not auto-train.
